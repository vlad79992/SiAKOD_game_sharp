# Замыкание кривой

# Описание
Игра "Замыкание кривой", выполненная в рамках предмета "Структуры и алгоритмы компьютерной обработки данных".
Игру создали студенты второго курса ИВТ Берсеков Айдамир Мухадинович и Мошков Владислав Олегович на языке программирования  C# с использованием SFML для рендера.

## Компиляция

Для запуска достаточно ввести команду ```dotnet run``` в папке с проектом, для запуска нужен .NET Runtime.

Для компиляции в папке с проектом нужно ввести команду ```dotnet publish```, это создаст независимый от .NET исполняемый файл.

Компиляция и запуск возможны на всех основных платформах при наличии .net SDK.
